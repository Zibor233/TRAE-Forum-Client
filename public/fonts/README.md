# Emoji font

Noto Color Emoji, unmodified, from googlefonts/noto-emoji tag v2.047.
Source: https://github.com/googlefonts/noto-emoji/blob/v2.047/fonts/NotoColorEmoji.ttf
License: SIL Open Font License 1.1, included in OFL.txt.

Bundled as an application web font so Linux packages also work offline without a system emoji font. This does not install or modify system fonts.
