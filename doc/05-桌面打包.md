# TRAE Forum Client 桌面版

桌面版使用 Electron，前端和代理都包含在安装包中。用户不需要安装 Node.js，也不需要手工运行代理。授权页、外部链接交给默认浏览器打开，登录仍使用官方 User API Key 的复制授权结果流程。

## 构建矩阵

| 系统 | 架构 | 输出 |
| --- | --- | --- |
| Windows 10/11 | x64 | NSIS 安装包、便携 EXE |
| macOS 13+ | x64（Intel） | DMG、ZIP |
| macOS 13+ | arm64（M 系列） | DMG、ZIP |
| Linux | x64 | DEB、AppImage、tar.gz |
| Linux / 麒麟 V10 适配目标 | arm64 / aarch64 | DEB、AppImage、tar.gz |

架构应按 `uname -m` 判断。飞腾、鲲鹏等 aarch64 环境选 arm64；此包不覆盖龙芯 LoongArch、MIPS，也不覆盖 32 位 ARM。

## 本机命令

构建机需要 Node.js 24 和 npm；首次执行 `npm ci`。

```sh
npm run desktop                  # 构建前端并启动桌面版
npm run desktop:pack             # 当前系统的解包目录
npm run desktop:win              # 在 Windows 上生成 x64 安装版及便携版
npm run desktop:mac              # 在 macOS 上生成 Intel 和 Apple Silicon 两种包
npm run desktop:linux            # 在 Linux 上生成 x64 和 arm64 的包
npm run desktop:linux:arm64      # 仅生成 Linux ARM64 包
npm test
node scripts/smoke-desktop.mjs   # 独立临时用户目录中运行启动检查
```

输出位于 `release/`。完整 macOS 打包应在 macOS 上运行；Linux 安装包应在 Linux 构建机上生成。Windows 当前机器不能替代全部目标系统的构建和运行验证。

## 自动构建

`.github/workflows/desktop.yml` 提供 Windows x64、macOS x64/arm64、Linux x64/arm64 五个任务。上传到 GitHub 仓库后，可在 Actions 中手动运行，或推送 `v*` 标签触发。每个任务先运行测试、类型检查和前端构建，再生成对应的安装包，上传至 Actions Artifacts。

推送版本标签后，全部构建成功会自动上传至 GitHub 预发布版。客户端启动 15 秒后静默检查 Releases，成功结果缓存 6 小时，失败延迟 15 分钟重试；仅发现新版本时提示，不自动下载安装。

## 麒麟 V10 ARM64 验证

麒麟 V10 的不同 SP 版本、桌面版和服务器版依赖可能不同。ARM64 构建不等于已在所有麒麟 V10 机器验证通过。应使用桌面环境，在实际目标机器验证登录、图片、粘贴上传、草稿、消息和外部授权跳转。

ARM64 试用压缩包附带 `check-linux.sh`。仓库中也可执行以下只读检查：

```sh
sh scripts/check-linux.sh
# 将 tar.gz 解压后，可检查主程序缺少哪些动态库：
sh scripts/check-linux.sh /实际解压路径/trae-forum-client
```

从 Windows 交叉生成 tar.gz 时，需要在交付前运行
`python scripts/fix-linux-archive.py release/TRAE-Forum-Client-0.1.0-beta.1-linux-arm64.tar.gz`
修正 Unix 可执行权限。Linux 原生构建无需此步骤。

优先尝试 DEB 安装包（仅适用于使用 dpkg 的桌面版本）：

```sh
sudo apt install ./TRAE-Forum-Client-0.1.0-beta.1-linux-arm64.deb
```

AppImage 需要系统的 FUSE 支持；不具备 FUSE 时可优先用 DEB 或 tar.gz。如果启动报动态库不存在，以 `ldd` 输出和单位的软件源为准补齐 GTK3、NSS、X11、ALSA、GBM 等依赖，不要更换系统 glibc。

默认保留 Chromium 沙箱，不自动添加 `--no-sandbox`。单位策略禁用用户命名空间时，应由管理员按本机安全策略配置 Chromium 沙箱。图形驱动异常时可试运行 `trae-forum-client --disable-gpu`，仅用于定位驱动问题。

## 数据和发布

登录信息、草稿等由 Electron 用户目录中的 Chromium 存储保存，桌面源固定为 `trae://app/`，不会因本地代理端口变化丢失登录。浏览器版与桌面版的数据不自动互通。

Windows 本地包未配置代码签名。macOS 工作流当前生成未公证测试包，系统可能阻止打开；正式对外分发需要 Apple Developer ID 签名、公证。准备证书后，通过 CI Secret 配置签名，并启用 `mac.notarize`，不要把证书或密码放进仓库。
