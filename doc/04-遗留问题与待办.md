### 信息流向下滚动时画面「闪一下」

| 项 | 内容 |
| --- | --- |
| 记录/修复时间 | 2026-11-05 记录，2026-11-05 修复 |
| 现象 | 发现页 / 分类信息流向下滚动时画面短暂抖动，长列表、多卡片高度下均可复现 |
| 根因 1 | `FeedCard` 封面比例是运行时状态：初始 `4/3`，图片 `onLoad` 后按真实比例修改，每次解码都让卡片高度跳变 |
| 根因 2 | CSS `columns` 在分页追加时重新平衡，已渲染卡片跨列移动 |
| 根因 3 | 图片只有 `loading="lazy"`，无 `decoding`，占位色接近白色 |
| 修复 | `feedCardRatio()` 按 id 稳定取 4/3 / 1 / 3/4；`useColumnCount()` + `distributeColumns()` 改用 flex 列容器，新卡只追加到最短列列尾；封面占位改 `bg-line/30`；`img` 加 `decoding="async"` |
| 验证文件 | `src/components/FeedCard.tsx`、`src/pages/FeedPage.tsx` |

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 5 秒滚动 layoutShift 总分 | 0.3758 | 0 |
| 最长单次 shift | 0.1445 | 0 |
| shift 条目数 | 6 | 0 |
| 采样 32 帧卡片跨列/高度跳变 | 有（83px 级） | 0 |
| 无宽高的 `img` | 209 / 506 | 0 |
| `decoding` | 全部 none | async |

追加策略（「往下排列，别往上推」）：追加前 `captureAnchor()` 记录视口内首个卡片 `top`，`useLayoutEffect` 同帧比较并按 `delta > 0.5` 补偿；根容器 `[overflow-anchor:none]`；底部固定 56px sentinel + `IntersectionObserver(rootMargin: 0px 0px 1200px 0px)`。

**已接受的残留**：滚到绝对底部再触底加载时，页脚与 sentinel 会被推离视口，实测每次追加 CLS ≈ 0.1678（3 次合计 0.5021）；正常滚动（未贴底）时为 0。要降到 <0.02 需把页脚/加载条改为 sticky/fixed 或自动吸底，与「保持 scrollTop 不变」冲突，暂不采用。
