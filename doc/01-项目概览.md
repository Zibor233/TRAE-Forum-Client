# 01 · 项目概览

更新时间：2026-11-05
一句话摘要：这是一个基于 `forum.trae.cn` 的 Discourse 后端、用纯前端实现的第三方 Web 客户端，走向小红书式瀑布流 + 飞书式正文排版的「轻读」体验。

## 项目是什么

| 项 | 内容 |
| --- | --- |
| 后端 | `https://forum.trae.cn`（Discourse，官方公开 API） |
| 前端 | 纯前端 SPA，无自建后端业务逻辑；所有请求经本机 Node 代理转发 |
| 视觉方向 | 信息流仿小红书（瀑布流 / 文字卡封面）；详情正文仿飞书（16px、1.75 行高） |
| 路由 | Hash 路由：`#/`、`#/c/{id}`、`#/categories`、`#/search?q=`、`#/topic/{id}`、`#/notifications`、`#/messages`、`#/u/{username}`、`#/me` |
| 登录 | Discourse User API Key（`User-Api-Key` 请求头），密钥仅存本机 |
| 当前位置 | `D:\dev\TRAE-Forum-Client`（2026-11-05 从 `C:\Users\17431\Documents\Trae-CN\temp_20261104_01` 整体迁移） |

## 目录结构

| 路径 | 作用 |
| --- | --- |
| `src/api.ts` | 全部接口封装、错误归一化、缓存读写、预取入口（654 行） |
| `src/App.tsx` | 路由解析、全局会话、页面装配、发帖弹层（416 行） |
| `src/types.ts` | Discourse 返回结构类型（Topic / Post / Notification / Chat 等） |
| `src/index.css` | 语义色板（浅/深两套 CSS 变量）、正文排版、封面样式 |
| `src/pages/FeedPage.tsx` | 信息流：分类 Tab、分类工具条、瀑布流分列、翻页锚定 |
| `src/pages/TopicModal.tsx` | 话题详情弹层：媒体轮播、楼层定位、回复、点赞 |
| `src/pages/NotificationsPage.tsx` | 通知：两 Tab、同楼层点赞合并、分页与补偿 |
| `src/pages/MessagesPage.tsx` | 消息：一体式左右栏、气泡、表情、向上翻页 |
| `src/pages/ProfilePage.tsx` | 个人主页：笔记 / 点赞 / 收藏 / 关于 |
| `src/pages/SearchPage.tsx` | 搜索：官方 `/search.json` 结果 |
| `src/pages/CategoriesPage.tsx` | 分类全集：一级分类 + 可展开子分类 |
| `src/components/FeedCard.tsx` | 信息流卡片：图片封面、纯色封面、文字封面 |
| `src/components/Composer.tsx` | 发帖 / 回复编辑器：类别、标签、工具条、图片上传 |
| `src/components/Sidebar.tsx` | 桌面侧栏与移动底栏（品牌区、导航、更多菜单） |
| `src/components/AuthModal.tsx` | User API Key 授权面板 |
| `src/lib/auth.ts` | RSA 密钥生成、payload 解密、登录态存储 |
| `src/lib/requestQueue.ts` | 全局请求队列（并发 4、优先级、300ms 合并） |
| `src/lib/cache.ts` | localStorage 版 SWR 缓存（版本 + TTL） |
| `src/lib/errors.ts` | 错误状态码 / Retry-After 归一化 |
| `src/lib/author.ts` | 无 `users` 字段时的话题作者补全（串行 + 负缓存） |
| `proxy/server.mjs` | 本地代理：CORS、60 秒缓存、读令牌桶、写白名单 |
| `scripts/dev.mjs` | 一条命令同时启动代理与 Vite |
| `dist/` | 生产构建产物（`npm run build` 输出） |
| `doc/` | 本进度文档目录 |

## 技术栈

| 层 | 选型 | 版本 / 说明 |
| --- | --- | --- |
| UI | React | 18.3（函数组件 + hooks，无状态库） |
| 语言 | TypeScript | 5.6，`npx tsc --noEmit` 通过 |
| 构建 | Vite | 5.4（`@vitejs/plugin-react` 4.3） |
| 样式 | Tailwind CSS | 3.4 + PostCSS 8.4、autoprefixer 10.4 |
| 加密 | jsencrypt | 3.5（RSA 2048 / PKCS#1 v1.5） |
| 代理 | Node 原生 `http` | `proxy/server.mjs`，无 Express 等框架 |
| 兼容 | Tailwind 语义 token | `ink/sub/line/paper/surface/soft/accent` 等，浅深两套值 |
